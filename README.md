# OEE Calculator Dashboard

OEE Calculator Dashboard is a lightweight Python application for calculating Overall Equipment Effectiveness (OEE) using production shift data.

The project evaluates equipment availability, performance and quality, then combines them into a final OEE score. It also generates simple reports and visual summaries.

## Features

- Availability calculation
- Performance calculation
- Quality calculation
- Overall OEE score
- Shift history
- Console dashboard
- Report generation
- Simple charts

## Project Structure

```
core/
dashboard/
data/
utils/
```

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```
